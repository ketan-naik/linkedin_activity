# 🚀 LinkedIn Data Engineering Growth Copilot (100% Free)

An AI-powered LinkedIn growth and audience-building extension tailored specifically for **Data Engineers**. 

---

## 🌟 Key Features

1. **✨ In-Feed Smart DE Comment Assistant**:
   - Injects an `✨ AI DE Reply` button into every post's comment box on LinkedIn.
   - Generates **3 distinct technical persona styles**:
     - 💡 **Practical Nuance**: Pipeline edge cases, partition/memory tuning, dbt incremental logic, OOM traps.
     - ⚖️ **Architectural Trade-off**: Cost vs. latency, DuckDB vs. Spark, Lakehouse vs. Warehouse.
     - ❓ **Senior Inquiry**: Thoughtful questions about data contracts, idempotency, and production failures.
     - ⚡ **Quick Punchy Insight**: Sharp 2-sentence takeaways.
   - **Optional Auto-Like**: Automatically likes the post when you insert your comment.

2. **✍️ Data Engineering Post Studio (Side Panel)**:
   - Topic Matrix: Spark, Iceberg/Delta Lake, dbt, Kafka streaming, DuckDB, Polars, Data Modeling.
   - 5 Proven Technical Frameworks:
     - 🏗️ *System Design Case Study*
     - ⚔️ *Tool Benchmark & Comparison*
     - 💥 *Gotchas & Incident Breakdown*
     - 💻 *PySpark / SQL / Python Code Tip*
     - 🚀 *Career & Mindset*
   - Unicode Formatting Toolbar (**Bold**, *Italic*, 🔹, 👉, ✅, code blocks).

3. **🎣 Viral Hooks Optimizer**:
   - Generates 3 high-converting hooks for any topic to maximize impressions and dwell time.

4. **📁 Local Drafts Manager & 100% Privacy**:
   - Store favorite drafts locally in your browser.
   - Your API key stays in your local browser storage—never sent to any external server.
